# 위치정보법 점검 — 개인이 무료로 전 세계에 내도 되는가 (2026-10-09 조사)

## 가족끼리만 쓰기로 함 (2026-10-09 결정)

사업자등록을 하지 않기로 했으므로 **외부 배포는 하지 않는다.** 우리 가족 폰에만 직접 깐다.
그래서 아래 "신고하면 지켜야 하는 것" 중 아이 폰 위치 확인 알림은 **꺼 두었다**
(`CommandHandler` 의 `shareNotice.show` 두 줄 주석). 코드와 14개 언어 문구는 남아 있다.

상용 배포를 다시 검토할 때 할 일:
1. 사업자등록 → 위치기반서비스사업 신고(출시 후 1개월 안), 또는 "각 가족이 자기 Firebase 를
   쓰는 구조"(운영자가 위치를 받지 않음)로 바꾸고 위치정보지원센터에 확인
2. `shareNotice.show` 주석 풀기(아이 폰 즉시 통보)
3. 아이 연결 화면에 **법정대리인 동의 + 아이 본인 동의** 화면 만들기 — 2023년 6월 방통위가
   자녀 안심 앱 5곳(구글코리아 포함)에 과태료 90만~420만 원을 매긴 이유가 바로 아이 본인 동의
   누락과 제공 일시 미통보였다
4. `docs/legal/` 약관·처리방침 빈칸 채워 게시, 한국 비공개 테스트부터
5. 광고를 붙이면 "사업으로 영위"에 가까워지고 사업소득 신고 문제도 생긴다

그대로 켜 둔 것(가족만 써도 해가 없다): 명령의 `requestedBy` 기록, 30일 정리(우리 가족은
영구 보관 예외), 플레이 `isMonitoringTool` 표시, App Check(콘솔에서 안 켜면 아무것도 안 막음).

> **법률 자문이 아니다.** 법령 원문(국가법령정보센터 기준 2025-10-01 시행본)과 위치정보지원센터
> 안내, 로펌·실무 자료를 읽고 이 앱에 대어 본 정리다. 신고 전에 위치정보지원센터
> (02-588-0185, www.lbsc.kr)에 아래 "물어볼 것"을 그대로 물어 확인한다.

## 결론

**무료·소수·개인이라는 이유로 빠지는 길은 찾지 못했다.** 한국 사용자에게 내려면
**위치기반서비스사업 신고**가 필요하다고 보는 것이 안전하다. 다만 무거운 쪽(위치정보사업
**등록**, 법인 필요)은 이 앱에 해당하지 않아 보이고, 신고는 무료·온라인이며 1인 사업자는
**출시 뒤 1개월 안에** 해도 된다.

| 질문 | 답 | 근거 |
|---|---|---|
| 무료라서 빠지나? | 빠진다는 조문·해석을 못 찾음 | 법은 "사업으로 영위"만 말한다(제2조 7호). 실무 자료는 유·무료가 아니라 **서버로 보내는지**를 기준으로 본다 |
| 사용자가 적어서 빠지나? | 아니다 | 규모 기준이 없다 |
| 빠지는 경우는? | 위치를 **폰 안에서만** 쓰고 서버로 안 보내는 경우, 개인이 아닌 사물 위치만 다루는 경우 | 위치정보지원센터 "비신고 대상" |
| 이 앱은? | 아이 위치를 서버(Firebase)로 보내 보호자에게 보여준다 → **신고 대상** | |
| 위치정보사업 **등록**도 필요한가? | 아마 아니다 | 등록은 "위치를 모아 **다른** 위치기반서비스사업자에게 제공하는 사업"(제2조 6호·제5조). 이 앱은 제 서비스에 직접 쓴다 |
| 1인은 언제 신고? | 사업 개시 뒤 1개월 안 | 제9조의2(소상공인·1인 창조기업) |
| 사업자등록이 필요한가? | 신고 서류에 사업자등록증이 있다 | 위치정보지원센터 신고 요건. 사업자등록 자체는 홈택스에서 무료 |
| 비용 | 신고 수수료 없음. 등록면허세가 해마다 나올 수 있음 | 방송미디어통신위원회 안내 |
| 안 하면 | 3년 이하 징역 또는 3천만 원 이하 벌금 | 제40조 |

## 신고하면 지켜야 하는 것 — 코드로 한 것과 안 한 것

| 의무 | 조문 | 상태 |
|---|---|---|
| 이용약관에 정해진 항목을 적고 동의 받기 | 제18·19조 | **초안 있음** `docs/legal/location-terms.md`. 앱 안 동의 화면은 **아직 없음** — 약관이 확정되고 주소가 생기면 아이 폰 연결 화면에 붙인다 |
| 개인위치정보 처리방침 공개 | 제21조의2 | **초안 있음** `docs/legal/location-privacy-policy.md` |
| 보호자(제3자)에게 줄 때마다 아이에게 "누가·언제·왜" 즉시 알리기 | 제19조 ③ | **했음** — '지금 위치 확인'·'실시간 보기' 때마다 아이 폰에 소리 없는 알림(`child/LocationShareNotice`) |
| 수집·이용·제공사실 확인자료 자동 기록·보존 | 제16조 ② | **했음** — 명령 문서에 보낸 보호자(`requestedBy`)와 시각이 남고, 명령은 6개월 보관(`HistoryCleaner.KEEP_RECORD_DAYS`) |
| 목적을 이루면 파기 | 제23조 | **했음** — 위치·알림 30일 자동 삭제 |

| 유출·변조 방지 조치, 위치정보관리책임자 지정 | 제16조 ①, 제21조의2 | Firebase 보안 규칙·App Check. 책임자는 운영자 본인으로 적는다 |

## 위치정보지원센터에 물어볼 것

1. 개인 개발자가 **무료**로 배포하는 자녀 위치 확인 앱(위치를 자체 서버로 전송)도 위치기반서비스사업 신고 대상인가?
2. 사업자등록 없이 신고할 수 있는가? 없다면 간이·면세 사업자로 등록해도 되는가? 1인 창조기업 1개월 유예가 적용되는가?
3. 아이 폰을 **보호자가 직접 설치하고 연결**하는 구조에서, 14세 미만 법정대리인 동의를 확인하는 방법으로 무엇이 인정되는가?
4. 8세 이하 아이에게 제26조(서면 동의서 + 증명 서류)를 꼭 써야 하는가, 아니면 제25조 법정대리인 동의로 충분한가?
5. 보호자가 볼 때마다 아이 폰에 띄우는 알림(누가·언제·목적)으로 제19조 제3항 즉시 통보가 되는가?

## 전 세계로 내는 것

한국 법은 **한국 사용자**에게 서비스할 때 걸린다. 다른 나라로 내면 그 나라 법이 붙는다.
작은 무료 앱이 실제로 단속될 가능성은 낮지만, 법은 규모로 면제해 주지 않는다.

- **유럽(GDPR)**: 아이 위치는 민감하게 다뤄진다. 처리방침·동의·삭제 요청 처리가 필요하다(초안에 있음). 유럽 대리인 지정 의무가 걸릴 수 있다.
- **미국(COPPA)**: 13세 미만 아이의 정밀 위치를 모으려면 "검증 가능한 부모 동의"가 필요하다.
- **구글 플레이**: 나라와 상관없이 "감시 앱" 정책을 따른다 — 매니페스트 `isMonitoringTool=child_monitoring`(**넣었음**), 상시 알림(있음), 아이콘 숨기지 않기(안 숨김), 스토어 설명에 감시 기능을 분명히 쓰기.

**권하는 순서**: 한국에만 먼저 낸다(플레이 콘솔에서 국가 선택) → 신고와 동의 화면을 끝낸다 →
다른 나라는 그다음에 하나씩 연다. 14개 언어는 그대로 둬도 된다 — 언어와 출시 국가는 별개다.
