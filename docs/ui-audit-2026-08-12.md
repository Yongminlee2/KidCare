# 전체 화면 UI 점검

## 점검 범위

- 공통/연결: 역할 선택, 보호자 시작 방법, 보호자 초대 번호, 자녀 연결, 권한 안내
- 보호자: 지도, 알림, 관리 상·하단, 예약 목록·편집, 장소 목록·편집
- 자녀: 자녀 홈, 메시지 수신, 핸드폰 찾기
- 점검 기기: 1080 x 2400 Android 에뮬레이터
- 연결된 실사용 휴대폰과 기존 앱 데이터는 변경하지 않음

## 화면별 결과

1. 역할 선택 — 정상. 마스코트, 아이보리 배경, 보라색 주요 버튼이 일관됨.
2. 보호자 초대 번호 — 정상. 번호 카드와 보조 버튼의 우선순위가 명확함.
3. 보호자 시작 방법 — 수정 완료. 영어 `Cancel`을 `취소`로 통일함.
4. 자녀 연결 — 수정 완료. 두 입력창의 힌트가 겹치던 문제를 제거하고 외곽선과 높이를 통일함.
5. 권한 안내 — 정상. 마스코트, 설명 카드, 주요 버튼이 새 테마와 일치함.
6. 보호자 지도 — 정상. 새 상단 카드, 위치 마커, 경로 패널, 하단 내비게이션이 적용됨.
7. 보호자 알림 — 정상. 선택기, 설명 카드, 스위치, 빈 상태가 테마와 일치함.
8. 보호자 관리 — 정상. 소리 제어, 핸드폰 찾기, 메시지 영역이 보라·분홍 강조 체계를 따름.
9. 보호자 관리 하단 — 정상. 입력창과 알람 영역의 외곽선, 버튼, 간격이 일관됨.
10. 보호자 예약 목록 — 정상. 빈 상태와 주요 추가 버튼이 명확함.
11. 보호자 예약 편집 — 정상. 요일·시간·소리 선택과 저장 버튼이 깨짐 없이 표시됨.
12. 보호자 장소 목록 — 정상. 빈 상태와 장소 추가 버튼이 명확함.
13. 보호자 장소 편집 — 수정 완료. 장소 이름 입력창을 공통 입력 컴포넌트로 통일함.
14. 자녀 홈 — 정상. 큰 마스코트 카드와 권한 복구 버튼이 읽기 쉬움.
15. 자녀 메시지 — 정상. 보라색 배경과 확인 버튼이 새 디자인에 맞음.
16. 자녀 핸드폰 찾기 — 정상. 복숭아색 긴급 화면과 마스코트, 정지 버튼이 명확함.

## 발견하여 수정한 항목

- 자녀 연결 화면 입력 힌트 중복 및 글자 겹침
- 장소 편집 화면만 공통 입력 디자인이 적용되지 않던 문제
- 보호자 시작 방법 팝업의 영어 취소 버튼

## 접근성 확인 범위

- 캡처상 주요 버튼은 충분한 크기이며 선택 상태와 비활성 상태가 색과 형태로 구분됨.
- 글자 잘림, 컨트롤 겹침, 화면 밖으로 밀린 주요 동작은 확인되지 않음.
- TalkBack 읽기 순서, 최대 글자 크기, 색각 보정 모드는 별도 실기기 검사가 필요함.

## 이동 경로 정확도 보완

- 위치 요청이 가능한 한 정확한 GPS 값을 기다리도록 설정하고, 한 번에 묶여 들어온 위치들도 시간순으로 모두 처리함.
- 이동 경로에는 정확도 반경 30m를 초과하는 새 위치를 기록하지 않도록 기준을 강화함.
- 오래된 경로 데이터 중 정확도가 매우 낮은 점은 표시에서 제외하고, 위치 정확도와 이동 속도를 반영해 급격한 지그재그를 완화함.
- 10분 이상 끊겼거나 물리적으로 불가능한 속도로 튄 구간은 직선으로 잇지 않고 경로를 분리함.
- 건물 내부, 고층 건물 사이, 기기 GPS 성능에 따른 실제 오차는 앱 보정만으로 완전히 제거할 수 없음.

## 결론

점검한 16개 화면에 새 파스텔 UI가 적용됐고, 확인된 세 가지 불일치와 이동 경로 표시 정확도 보완을 완료함.
